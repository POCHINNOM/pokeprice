Pokémon TCG API
카드 이미지, 이름, 세트 정보, 희귀도 등 모든 카드 메타데이터를 제공합니다. 공식 TCG 데이터를 기반으로 운영되는 무료 API입니다.

TCGPlayer
미국 최대 포켓몬 카드 거래 플랫폼. 시장가(Market Price), 최저가, 중간가, 최고가 데이터를 실시간으로 제공합니다.
tcgplayer.com ↗
포켓몬 이름 데이터베이스
